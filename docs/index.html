Limitations

  • Small task sets per track and automatic scoring on keywords, numbers, JSON and executed code; a human check of a sample is planned.
  • One machine, one quantisation per model, English prompts except the Dutch track.
  • Model-written code is executed on the benchmark machine.
Prompts, scoring rules, raw answers and scripts are in the repository (MIT licence). Run it on your own Mac mini and send a pull request. See the Hairball page for the worst answers and the Blind vote page to judge answers yourself.
